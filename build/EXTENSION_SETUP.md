# TurboDM Browser Extension Setup Guide

Thank you for installing TurboDM! 

## Quick Setup Instructions

### For Chrome Users:

1. **Open Chrome Extensions Page:**
   - Click the menu icon (⋮) in the top right
   - Go to **Settings** → **Extensions** → **Manage extensions**
   - Or paste this in address bar: `chrome://extensions`

2. **Enable Developer Mode:**
   - Toggle **Developer mode** in the top right corner (switch should turn blue)

3. **Load Unpacked Extension:**
   - Click **Load unpacked**
   - Navigate to the TurboDM installation folder:
     ```
     C:\Program Files\TurboDM\resources\browser-extension
     ```
   - Select the `browser-extension` folder
   - Click **Open** → **Select Folder**

4. **Done!** 
   - You should see the TurboDM extension in your extensions list
   - Pin it to your toolbar for easy access

### For Edge Users:

1. **Open Edge Extensions Page:**
   - Click the menu icon (•••) in the top right
   - Go to **Extensions** → **Manage extensions**
   - Or paste this in address bar: `edge://extensions`

2. **Enable Developer mode:**
   - Toggle **Developer mode** in the left sidebar (switch should turn blue)

3. **Load Unpacked Extension:**
   - Click **Load unpacked**
   - Navigate to the TurboDM installation folder:
     ```
     C:\Program Files\TurboDM\resources\browser-extension
     ```
   - Select the `browser-extension` folder
   - Click **Select Folder**

4. **Done!**
   - The TurboDM extension is now active
   - You'll see a download button on video sites

## Features

Once enabled, the TurboDM extension provides:

✅ **Video Downloads** - One-click download from YouTube, Twitch, Vimeo, and more  
✅ **Direct Downloads** - Download files using TurboDM instead of browser  
✅ **Better Speed** - Leverage TurboDM's multi-connection downloading  
✅ **Smart Selection** - Automatically detects downloadable files  

## Troubleshooting

**Extension not showing?**
- Make sure Developer mode is enabled
- Verify the extension folder path is correct
- Restart your browser

**Downloads not working?**
- Install the new desktop app so the turbodm:// protocol is registered
- Check that TurboDM is listening on port 10101
- Open the extension popup: it should show **Desktop connected**.
- Use the right-click **Download with TurboDM** command or paste an HTTP link in the popup.
- After upgrading TurboDM, reload the extension in Chrome/Edge and accept its updated permissions.

**Need Help?**
- Check the TurboDM application logs
- Verify browser-extension folder contains manifest.json
- Restart TurboDM and your browser

## Capture and permission flow (1.3.1)

Update both the desktop installer and extension; older extensions cannot auto-start downloads in this app.

1. Click a direct downloadable link. Its normal browser navigation is stopped.
2. Approve the browser's **Open TurboDM** permission prompt.
3. TurboDM launches or comes to the front and opens **New download**, prefilled with the link.
4. Review the filename and options, then choose **Start download**. Only this action starts the transfer.

Chrome/Edge controls the external-app prompt. If you previously chose Always allow, the
browser can open TurboDM without asking again. TurboDM cannot override that browser choice.

For downloads generated by page scripts, the extension pauses Chrome and opens a handoff
page. Click Open TurboDM there to request permission, or explicitly choose Save in browser
instead. Declining or ignoring permission never silently resumes Chrome or starts a desktop transfer.
POST-only requests need browser continuation. A tiny file already completed before Chrome's
pause API runs cannot be rewound.

Explicit blob/data download anchors stage generated files up to 32 MiB in memory and show
the same confirmation dialog before saving. Larger blobs and inaccessible private APIs
may need the browser. Session headers travel separately over loopback, never inside the
protocol URL. Protected links may need recapturing after restarting the app.

The popup, video button and desktop share the Porcelain & Indigo theme.
